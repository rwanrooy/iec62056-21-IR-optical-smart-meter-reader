# IEC 62056-21 IR Optical Smart Meter Reader

Open-source infrared optical reader for smart meters using **IEC 62056-21**.

## Features
- Works with IEC 62056-21 compliant meters
- ESP32 / Arduino compatible
- Infrared optical interface
- Designed for smart meters and water meters

## Hardware
- IR LED + photodiode
- Compatible with USB-C optical heads
